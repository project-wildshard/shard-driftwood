# Driftwood's own paths for sdk 0.5.0

> Written by: Claude (opus, session 015pj4Rw), 2026-11-25

SDK 0.5.0 (sharddev plan `opus-2026-11-24-sdk-migrate-static`, row R2)
moves a shard repo's `public/` into `src/static/` and builds into
`out/<slug>`. Jake: "I'd rather have all the source code of the game
zone be in ./src/ and the generated shardfile output in ./out/ and
remove the ./public/ directory", and "just the move without the rename",
so every name inside the shard stays the same and the product is
byte-identical.

`wildshard upgrade 0.5.0` does the move itself. This commit is the
part it lists as manual: the places in this repo that name the old
paths.

- `scripts/ci21-source-product.mjs` and `test/fixtures/builtProduct.ts`
  sealed `src/` plus `public/` and allowed two kinds of copies there
  (publish-public's `src/assets/public/` aliases and the builder's map
  `top.webp`). Neither exists on 0.5.0, so the sealed inputs are exactly
  the tracked `src/` tree. The control test now proves a static mount
  is an ordinary sealed input instead of proving the aliases.
- `scripts/blender/targets.json`, three fixtures, three tests and
  `docs/design.md`: `public/assets/` is `src/static/assets/`.
- Not here: `publish.yml`, `scripts/publish-shard.mjs` and
  `scripts/keep-copy.mjs` are kit-owned; their `public/` mentions are
  fixed in repo-kit for every shard repo.
