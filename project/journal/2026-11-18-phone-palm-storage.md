# Driftwood phone palm storage

> Written by: Codex

> **State:** Phone Low world mesh, 2026-11-18 (MG11, J410).

The single phone palm batch was the largest remaining named shard GPU
buffer group at Driftwood control, 3.71 MB. Store its wind as half
floats and weld only corners with identical packed attributes. The
existing phone GLB compactor can then use a smaller indexed layout.

The generated file contains the same 41,256 triangles, in the same
order with the same colors. Welded vertices fall from 123,768 to
102,131. The largest decoded position difference is 4.85 mm and the
largest wind-channel difference is 0.00391. The phone palm blob's
compressed cost falls from 3.22 to 0.90 MB and its declared GPU
cost from 3.22 to 2.13 MB. Other named files matched by hash. Local
checks, 55 shard tests and the format validator passed.

The nine-view Phone Low spawn board matches the accepted island look,
with equal draw and triangle counts at each camera. Re-stamped the
existing curated cove cards and verified their hashes. The author
path `wildshard check` passed.
