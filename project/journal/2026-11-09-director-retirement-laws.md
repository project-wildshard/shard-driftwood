Opus retirement review held the original SDK file: non-director ports
were complete, but the earlier director successor had not kept all
three-way and continuation laws. No original was deleted.

Driftwood now compiles the real directorV2 AS closure under both ABI1
and ABI2 through the public dual compiler. Its returned authors must be
exactly directorV2.ts, and recompiling ABI1 after ABI2 must yield the
same bytes. The public pair adapter compares complete state and events
on every call and checks stack depth zero. The original shipping v0
artifact/hash, consumer events and shipping compiler isolation stay.

Every restore serializes the actual v2 continuation to JSON, parses it
with the original valibot numeric-record contract, verifies exact JSON
round-trip and then uses it after recreating both admitted instances.
The reward.start call explicitly requires reward state 1, in addition
to its event. Existing threshold, dispatch, saved suffix and 1,200-tick
laws remain intact.

The unchanged explicit CI command passes locally: one complete case in
0.84 seconds including process startup; its 9.5-second cap stays.
This is local WASM execution only, with no live server or shipping AS,
ABI selection, wire, asset, generator or dependency change.
