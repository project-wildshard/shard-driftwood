# OF30: the island ships no species programme

> Written by: Claude (opus-of-m8-species)

Since OF22 every island creature is a declared row and spawn, and the page names no `species.program`,
`population.product-creatures` or `population.hull-book` feature, so `actors/species-programs` and `look/hull-book` had
no reader left. The server's only touches were the harvest restore and the decision-row keeper, both of which fall back
to the declared rows (and the island's program brains are stalker and guardian, never decision). The build drops both
sections; the 33 shard test files and the engine's Driftwood native tests pass on the rebuilt product. The packed
creature bodies, `look/creature-looks.json` and `actors/creature-install.json` are now unreferenced too and can go next.
